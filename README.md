# 📊 Analyse de Campagne Marketing Bancaire & Machine Learning

## 📝 Description du projet

Ce projet de Data Analysis et Machine Learning porte sur l’étude d’une campagne marketing bancaire à partir du dataset **Bank Additional Full**.  

L’objectif principal est d’analyser les données clients afin de comprendre les facteurs influençant la souscription à un dépôt à terme bancaire et de construire un modèle prédictif capable d’anticiper les réponses des clients.

Ce projet m’a permis de développer des compétences en :
- analyse de données,
- visualisation,
- préparation des données,
- machine learning,
- interprétation des résultats,
- et communication des insights métiers.

---

## 🎯 Objectifs du projet

- Comprendre le comportement des clients bancaires
- Identifier les variables influençant la souscription
- Réaliser une analyse exploratoire des données (EDA)
- Construire des modèles de Machine Learning
- Évaluer les performances des modèles
- Fournir des recommandations basées sur les données

---

## 📁 Dataset

Le dataset utilisé contient des informations sur :
- l’âge des clients,
- la profession,
- le niveau d’éducation,
- les contacts marketing,
- la situation financière,
- les campagnes marketing précédentes,
- et la variable cible : souscription ou non à un dépôt bancaire (`y`).

Dataset : **Bank Additional Full** récupérer sur Kaggle

## 📊 Résultats principaux

- Certains profils clients présentent une forte probabilité de souscription.
- Les campagnes précédentes influencent fortement les résultats futurs.
- La durée des appels marketing joue un rôle important dans la prédiction.
- Les modèles de Machine Learning permettent de prédire efficacement les réponses des clients.
